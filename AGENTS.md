Ponytail Rules

Before writing code:

1. Can existing code be reused?
2. Can shadcn/ui solve it?
3. Can the browser solve it?
4. Can an installed dependency solve it?
5. Can it be done in one function?

Prefer:

* less code
* fewer files
* fewer dependencies
* simpler solutions

Avoid:

* new abstractions
* custom hooks used once
* helper files used once
* over-engineering
